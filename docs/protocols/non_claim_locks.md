# GeniusRouter Non-Claim Locks

GeniusRouter currently does not prove:

- production readiness,
- routing correctness,
- classifier accuracy,
- semantic routing accuracy,
- cost savings,
- quality preservation,
- provider reliability,
- cache correctness,
- benchmark validity,
- security,
- fault tolerance,
- RCC-N completion,
- SOTA status as an evidence-backed benchmark result.

Allowed current claim:

GeniusRouter is an early FastAPI/LiteLLM routing scaffold for low/medium/high model tier routing, with Docker, Redis, Ollama, OpenRouter/API-provider compatibility, and config-based model selection.

Stronger claims require tests, benchmarks, routing decision evidence, and release validation.
