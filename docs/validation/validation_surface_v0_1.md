# GeniusRouter-SA v0.1 Validation Surface

## Valid v0.1 Claims

- GeniusRouter has a documented software architecture.
- GeniusRouter has a docs registry.
- GeniusRouter has non-claim locks.
- GeniusRouter has an AI operating contract.
- GeniusRouter has a routing decision contract target.
- GeniusRouter has a roadmap toward runtime hardening and RCC-N.

## Invalid v0.1 Claims

- production ready,
- benchmark validated,
- cost savings proven,
- routing accuracy proven,
- classifier accuracy proven,
- cache correctness proven,
- provider reliability proven,
- RCC-N complete.

## v0.1 Law

No routing claim without routing evidence.
No cost claim without benchmark evidence.
No production claim without tests.
