# GeniusRouter RCC Nexus Protocol

## Rule 1 — Read before patching

Before a runtime or docs patch, read:

1. `README.md`
2. `README_5_MINUTES.md`
3. `docs/context/repository_context_index.json`
4. `docs/context/rcc_nexus_index.json`
5. `rcc/nexus/route_map.json`
6. target folder README

## Rule 2 — Validate after patching

Run the validation commands declared by the route map.

## Rule 3 — Preserve boundaries

Never convert navigation quality into correctness proof.

## Rule 4 — Update geometry

If folders, routes, validation commands, evidence paths, or claim boundaries change, update RCC-N indexes and mini READMEs.
